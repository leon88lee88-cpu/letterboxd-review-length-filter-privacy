Privacy Policy

Last updated: September 2026

Letterboxd Review Length Filter does not collect, transmit, sell, or share users' personal information.

Website Content

The extension reads review text displayed on Letterboxd pages solely to calculate review word counts and apply the user's selected review-length filter.

All review processing occurs locally in the user's browser. Review text and other Letterboxd content are not transmitted to the developer or any external server.

Chrome Storage

The extension uses Chrome's storage API only to save the user's selected minimum review word count and filtering preferences.

These settings are used only to provide the extension's filtering functionality.

Data Collection

The extension does not collect:

  • Personal information
  • Browsing history
  • Authentication information
  • Financial information
  • Location information
  • Personal communications

Third Parties

User data is not sold, shared, or transferred to third parties. The extension does not use analytics, advertising trackers, or third-party data collection services.

Extension Purpose

Data accessed by the extension is used only for its single purpose: filtering Letterboxd reviews according to review word count.

Affiliation

Letterboxd Review Length Filter is an independent project and is not affiliated with, endorsed by, or sponsored by Letterboxd.
